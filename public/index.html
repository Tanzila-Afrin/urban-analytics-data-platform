Engineering architecture

A modular pipeline from raw observations to analytics.

Data processing workflow

Weather API / CSV→ Python ingestion→ Data validation→ InfluxDB→ Grafana

The project includes custom validation rules and a Great Expectations validation suite before records are loaded into the time-series database.

Data quality

Custom validation and Great Expectations checks assess data integrity, expected fields, ranges, and record consistency before database loading.

Time-series storage

InfluxDB stores weather measurements as time-series data, supporting time-based queries and analytical exploration.

Visual monitoring

Grafana provides a six-panel dashboard for monitoring temperature, humidity, precipitation, snowfall, wind speed, and cloud cover.
