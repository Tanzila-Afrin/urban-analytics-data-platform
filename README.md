# Urban Analytics Data Platform

## Overview

A unified data engineering and analytics platform
built using Microsoft Fabric.

The project integrates:

- NYC Taxi Trip Data
- OpenAQ Air Quality Data
- World Bank GDP Data
- European Central Bank Exchange Rates

## Architecture

The project follows the Medallion Architecture:

- Bronze: Raw data ingestion
- Silver: Data cleaning and transformation
- Gold: Analytical data modeling

## Technology Stack

- Microsoft Fabric
- OneLake
- PySpark
- Fabric Data Factory
- Fabric Warehouse
- SQL
- Power BI
- Git and GitHub
